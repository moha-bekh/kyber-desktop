# Custom TLS certificates generation

## Presentation

### General

Even during development, it is required to have TLS connections for multiple reasons:
* The development environment will be close to the production environment
* Quic requires TLS
* For a web client, it is required to serve files in a "Secure context" to have access to WebCodec API (and other APIs). Although this is not required when connecting to localhost, it is required when connecting to another machine

When deploying Kyber for end users, real certificates generated by an official certificate authority will be used instead.

### Web client case

To have a browser that trusts our certificate, it is required to create a custom Root CA. The root certificate can be added in trusted root CA on Chrome or in the browser.

It is still possible to force Chrome to connect to a website that has an untrusted certificate, WebCodec API will still be available.

### Current certificate limitations

A TLS certificate is valid only for a list of DNS or IP. The certificate is currently valid for:
* `kybertest`
* `localhost`
* `office.videolabs.io`
* `127.0.0.1`

It is possible to define `kybertest` in `etc/hosts` file in a computer to connect to another PC.

If it is required to complete the list, the commands to generate a new set of certificates is available below.

### Check alt names for an existing certficiate

It is possible to check the alt names for an existing certificate:
```
cat cert.pem | openssl x509 -noout -ext subjectAltName
```

Example:
```
$ cat kybertest_cert.pem | openssl x509 -noout -ext subjectAltName
X509v3 Subject Alternative Name:
    DNS:kybertest, DNS:localhost, DNS:office.videolabs.io, IP Address:127.0.0.1, IP Address:192.168.1.19, IP Address:192.168.1.197
```


## Command used to generate the certificates

### Create root certificate

```
CANAME=Kyber-RootCA
openssl genrsa -aes256 -out $CANAME.key 4096
openssl req -x509 -new -nodes -key $CANAME.key -sha256 -days 1826 -out $CANAME.crt -subj '/CN=Kyber Root CA/C=FR/ST=France/L=Paris/O=Kyber'
```

### Create the website certificate

```
KYBERTEST_CERT=kybertest
openssl req -new -nodes -out $KYBERTEST_CERT.csr -newkey rsa:4096 -keyout $KYBERTEST_CERT.key -subj '/CN=Kyber/C=FR/ST=France/L=Paris/O=Kyber'

cat > $KYBERTEST_CERT.v3.ext << EOF
authorityKeyIdentifier=keyid,issuer
basicConstraints=CA:FALSE
keyUsage = digitalSignature, nonRepudiation, keyEncipherment, dataEncipherment
subjectAltName = @alt_names
[alt_names]
DNS.1 = kybertest
DNS.2 = localhost
DNS.3 = office.videolabs.io
IP.1 = 127.0.0.1
IP.2 = 192.168.1.19
IP.3 = 192.168.1.197
EOF

openssl x509 -req -in $KYBERTEST_CERT.csr -CA $CANAME.crt -CAkey $CANAME.key -CAcreateserial -out $KYBERTEST_CERT.crt -days 730 -sha256 -extfile $KYBERTEST_CERT.v3.ext
```
